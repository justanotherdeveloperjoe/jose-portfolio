Linux kernel and BusyBox guest image (buildroot-bzimage68.bin, seabios.bin,
vgabios.bin)
https://github.com/copy/v86/tree/master/tools/docker
The guest boots an unmodified Linux kernel with a BusyBox-based root
filesystem, built with Buildroot (https://buildroot.org) and distributed by
the v86 project. The Linux kernel and BusyBox are each licensed under the
GNU General Public License, version 2. Source for the kernel and BusyBox is
available from https://www.kernel.org and https://busybox.net; Buildroot's
own configuration for this image is published by the v86 project above.

SeaBIOS and the Bochs/QEMU-derived VGA BIOS bundled here are distributed by
the v86 project under the same terms as the upstream SeaBIOS project
(https://www.seabios.org), licensed under the GNU Lesser General Public
License, version 3 (and, for portions derived from Bochs, version 2).

This desktop is a small browser experiment. Nothing you type here reaches
a server; the machine and its files exist only in your browser tab.
